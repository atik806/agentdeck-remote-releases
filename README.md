# AgentDeck Remote: Android releases

Control [AgentDeck](https://vibeflow.tech/agentdeck) on your PC from your phone,
end-to-end encrypted.

**Download:** get the latest `AgentDeck-Remote-vX.Y.Z.apk` from
[Releases](../../releases), open it on your phone, and allow "Install unknown
apps" when Android asks. Play Protect may warn because the app isn't from the
Play Store.

**Verify:** each release lists the APK's SHA-256 in `SHA256SUMS.txt` and the
signing-certificate fingerprint in its notes. Every release uses the same
certificate.

This repo only builds and hosts the APK; the source is private.
